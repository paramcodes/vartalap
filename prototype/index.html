Messenger shell prototypes

Five throwaway files. They exist to answer a question and to be deleted, not to become a component library. None of this ships. Where a prototype settled a question, the answer went into an ADR in docs/adr/ — the prototype is the evidence, the ADR is the decision.

  • desktop.html view at 1440+

    Start here. The four-column layout — icon rail, chats, transcript, details — and the collapse behaviour. The current reference for desktop. Try ?variant=A … ?variant=D to compare all four.

  • chat-view.html view at 375–480

    Bubbles, corner sets, timestamps, receipt ticks, the day divider. Where the 17.9998px radius was measured rather than assumed.

  • composer.html view at 375–480

    Entry, IME handling, Enter-vs-Shift+Enter, the attachment tray. Caught a real bug: keydown matched Enter without checking shiftKey.

  • settings.html view at 375–480

    The account / membership / device settings scopes — the thing ADR 0022 settled, shown rather than described.

  • index.html any width

    The token block itself, annotated. This is the source of the @theme every other prototype copies, so it is the file to copy from if a token ever changes.

Before editing a token: run bun run check:tokens. If it passes and you still changed one, you have silently diverged from ADR 0002.
