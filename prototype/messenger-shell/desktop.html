Two things this changes outside the layout

  • Dark mode is not a Messenger web feature. ADR 0002 built a full dark token set and called it fidelity. The web app has no dark mode; only the retired desktop app did. Keeping it is an invention, and a defensible one — but it should be our decision, not a fidelity claim.
  • Our composer has a send button; messenger.com does not. ADR 0050 chose one. Enter sends, on the web, per Meta's docs. Both can be true — mobile wants the button, and the split needs to be explicit rather than accidental.

Why there is no screenshot of the real thing

Every archived capture of messenger.com — 2016, 2018, June 2024, and today — returns the logged-out login shell, not the app. Facebook serves it through Comet, its CSS-in-JS system, so even a logged-in capture would yield no readable stylesheet; the widths live inside JavaScript. Closing this properly needs a logged-in browser with DevTools, resizing the window and reading the computed values. That is a ten-minute job for someone with an account, and it is the only way these numbers stop being ours.
